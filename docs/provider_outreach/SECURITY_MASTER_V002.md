# Point-in-Time Security-Master Provider Questionnaire

Status: unsent review draft; provider not selected

The common questionnaire in `V002_COMMON_QUESTIONNAIRE.md` is incorporated in
full. A prospective security-master provider should additionally confirm:

1. Are security, listing, share-class, and issuer identifiers stable and separately represented?
2. Are every listing type, active/inactive state, exchange transfer, relisting, delisting, merger, and recycled ticker retained with effective and first-known timestamps?
3. Can complete XNYS, XNAS, and XASE populations be reconstructed before each 09:25 cutoff from 2024-06-03 onward?
4. Are excluded security types explicitly classified rather than absent?
5. Can expected population counts and bounded negative coverage be certified for each snapshot?
